# Аудит Morning Brief — 2026-10-04–05

Исходная версия: `edde17b7fc025c6c5a91a68acdc010ff63fb312a`.
Проект предназначен для личной утренней сводки: Python собирает погоду,
праздники, котов и задачи, создаёт Markdown и HTML; React оформляет HTML;
Telegram и Windows toast включаются настройками. Это генератор статических
файлов, а не веб-сервис с аккаунтами и серверной базой данных.

## Результат исправлений

Исправлены все перечисленные воспроизводимые ошибки; назначение проекта сохранено.

- Валидация config до сетевых запросов, понятный код ошибки CLI, `--local-only`.
- Задачи: отдельное состояние недоступности, UTF-8 BOM, безопасное отображение текста.
- Telegram: проверяются и HTTP, и JSON `ok`; тела ошибок и секреты не логируются.
- Единый приоритет окружения над .env для Python, PowerShell и get_chat_id.
- Потоковая загрузка котов до 8 МБ, ограничение времени, HTTPS/домены, запрет redirects/SVG.
  Реальный API отдаёт также `s3.us-west-2.amazonaws.com/cdn2.thecatapi.com/images/`;
  разрешён только этот bucket/path. Частичный ответ API сохраняет доступные картинки.
- Обе HTML-версии встраивают картинки; React-версия также встраивает шрифты с лицензиями.
  Ошибки котов/праздников/задач не маскируются успешными состояниями.
- Исправлены переполнение карточек и длинные задачи; добавлены фокус ссылок и доступ
  ко всем скачанным котам. Ссылка «Коты» теперь ведёт к галерее.
- Windows VBS использует свой каталог и возвращает код дочернего процесса.
- Обновлены npm-зависимости, нижние границы Python-зависимостей и инструкции.
- Добавлены unittest, Vitest, Ruff, ESLint, Playwright и GitHub Actions.

### Оставшиеся ограничения и решения владельца

- Реальные Telegram sendDocument/getUpdates, доставка/открытие вложения и Windows toast
  не проверены: нужны токен, получатель и пользовательская Windows-сессия. Внешние
  сообщения и уведомления не отправлялись; эти ветки проверены тестовыми ответами.
- Браузерные тесты выполняются в Chromium. Safari/Firefox и реальное мобильное устройство не проверены.
- Источники API могут менять доступность, форматы, домены и покрытие стран;
  результат реального запроса — наблюдение в момент аудита, не обещание доступности.
- Нет дедупликации отправки, блокировки одновременных запусков, автоочистки output/cats
  и ротации логов. Для ежедневного использования нужно выбрать срок хранения и
  запускать одну копию по расписанию; старые данные автоматически не удаляются.
- Полного Python lock-файла нет; воспроизводимость обеспечивается проверками в чистом
  окружении, ограничениями прямых зависимостей и npm lock. Полное закрепление Python
  версий можно согласовать отдельно для целевых ОС.
- ESLint 9.39.5 имеет предупреждение EOL, но остаётся последней совместимой веткой
  для текущего eslint-plugin-react 7.37.5 (peer до ESLint 9). Уязвимости npm audit
  не обнаружены; переход линтера на ESLint 10 потребует замены/обновления React-плагина.
- GitHub Actions настроен на Linux/Python 3.11/Node 22 и Windows/Python 3.13/Node 24.
  Фактические результаты конкретного коммита доступны во вкладке Checks pull request.
